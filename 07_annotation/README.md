# Functional and Taxonomic Annotation

Scripts for running various annotation tools on the final vOTU dataset.

## Tools used:
- **CheckV**: Genome completeness and quality
- **iPHoP**: Host prediction
- **Taxmyphage**: Taxonomic classification
- **BACPHLIP**: Lifestyle prediction (lytic vs. temperate)

Each script includes setup commands (e.g., `conda`, `nohup`, threading).
