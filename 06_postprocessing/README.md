# Postprocessing and Filtering

This folder contains utility scripts for:
- Renaming vOTU IDs (e.g., `vOTU1`, `vOTU2`)
- Filtering matrices for vOTUs ≥10kb
- Removing duplicates
- Extracting subsets of CPM data for final analyses

## Example scripts:
- `01_rename_ids_to_vOTU.sh`
- `02_filter_10kb.sh`
- `03_filter_matrix_by_ids.sh`
